# ✨ About ATITHI

**ATITHI** is a premium full-stack Tourism & Luxury Cab Booking Platform inspired by the Indian philosophy of **"Atithi Devo Bhava"**.

The platform provides an elegant and seamless travel experience by combining modern UI/UX, secure authentication, intelligent booking management, luxury cab services, destination exploration, and an advanced admin dashboard into one production-ready application.

Designed with performance, scalability, and user experience in mind, ATITHI offers everything needed for a modern travel startup.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/ATITHI.git

cd ATITHI
```

---

## Install Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Install Backend

```bash
cd backend

npm install

npm run dev
```
